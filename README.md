# Isaac ROS UR3e Dev Workspace

Lab workspace for a **UR3e + Robotiq gripper** with **two Intel RealSense cameras**, running **Isaac ROS 4.4 / ROS 2 Jazzy** in the NVIDIA Isaac ROS container.

Use this repo to:

- Drive the real UR3e from ROS 2
- Publish calibrated camera extrinsics into TF
- Record joint waypoints and capture a dual-camera overlay dataset
- Run Isaac for Manipulation workflows (`ur3e_manilab`)

Remote: [Sounderya22/isaac-ros-ur3e-dev](https://github.com/Sounderya22/isaac-ros-ur3e-dev)

## Layout

Custom lab files live at the workspace root. NVIDIA / UR packages live under `src/` as nested git checkouts.

```
.
├── unified_calibration.json      # Source of truth: camera extrinsics, intrinsics, TCP notes
├── calibration_transforms.json   # Earlier eye-to-hand samples
├── camera_pose*.launch.py        # Eye-to-hand TF publishers (calibration history)
├── cp_corr_1.launch.py           # Eye-to-hand TF used in unified_calibration.json
├── cp_corr_2.launch.py
├── w_cp.launch.py                # Eye-in-hand TF (wrist_3_link → camera_1_link naming)
├── record_waypoints.py           # Record UR joint poses from /joint_states
├── record_waypoints_ros2.py      # Same recorder (ROS 2 variant)
├── capture_overlay_dataset.py    # Drive waypoints over RTDE, save cam1/cam2 + robot state
├── sweep_waypoints.json          # Recorded 8-pose workspace sweep
├── csamples.yaml / js_w.yaml     # Joint-space sample lists for calibration / validation
├── ur3e_robotiq.urdf             # Autogenerated URDF dump (do not edit by hand)
├── install_deps.sh               # Container package / rosdep / colcon helper
└── src/
    ├── isaac_ros_common/                 # Isaac ROS 4.4
    ├── isaac_ros_manipulation/           # Isaac for Manipulation (includes ur3e_manilab)
    ├── Universal_Robots_ROS2_Driver/     # UR ROS 2 driver (Jazzy)
    └── third_party/moveit_calibration/   # MoveIt hand-eye calibration (ros2-jazzy-updates)
```

Generated / large artifacts are gitignored: `build/`, `install/`, `log/`, `isaac_ros_assets/`, overlay datasets, and calibration-validation bags.

## Environment

Work **inside the Isaac ROS container**. On this machine the workspace is:

- Host: `/home/raaslab/workspaces/isaac_ros-dev`
- Container: `/workspaces/isaac_ros-dev`

```bash
cd ${ISAAC_ROS_WS}
source /opt/ros/jazzy/setup.bash
source install/setup.bash
```

First-time deps and UR driver build:

```bash
./install_deps.sh
```

That script:

1. Removes `ros-jazzy-sdformat-urdf` (it `dlopen`s a missing `libsdformat14` and kills `robot_state_publisher`)
2. Installs Python/system packages (`scipy`, `torch`, `matplotlib`, …)
3. Runs `rosdep` on `src/`
4. Builds `ur_robot_driver`

Rebuild after source changes:

```bash
cd ${ISAAC_ROS_WS}
colcon build --symlink-install
source install/setup.bash
```

## Calibration

Hand-eye calibration was done with **MoveIt 2** (`src/third_party/moveit_calibration`).

**Use `unified_calibration.json` as the current calibration.** It includes:

- `camera_1` eye-to-hand extrinsics (`world` → `camera_1_link`) from `cp_corr_1.launch.py`
- `camera_2` eye-in-hand extrinsics (`wrist_3_link` → `camera_2_link`) matching `w_cp.launch.py` numbers
- RealSense intrinsics at `1280x720` and `640x480`
- Optical-frame offsets, Isaac Sim USD quaternion convention, TCP / gripper notes

Isaac for Manipulation loads those extrinsics at runtime from `unified_calibration.json` into the `ur3e_manilab` static TF set (`static_transforms.launch.py`). Camera serials for that setup are in:

`src/isaac_ros_manipulation/isaac_ros_manipulation_bringup/config/sensors/realsense_camera_ids/ur3e_manilab.yaml`

Standalone TF publishers (useful for debugging a single transform):

```bash
# Scene camera (eye-to-hand) — this is the current camera_1 pose
ros2 launch camera_pose.launch.py          # older sample
ros2 launch cp_corr_1.launch.py            # current camera_1 (matches unified_calibration.json)

# Wrist camera (eye-in-hand). Note: this file publishes child frame camera_1_link.
ros2 launch w_cp.launch.py
```

The `camera_pose*.launch.py` / `cp_corr_*.launch.py` files are calibration iterations, not four live cameras.

## Waypoint recording and overlay dataset

Used to validate camera projection across the workspace (8-pose corner sweep, 2026-07-14).

1. Start the robot driver so `/joint_states` is publishing.
2. Freedrive the arm and record joints:

```bash
python3 record_waypoints.py
# or
python3 record_waypoints_ros2.py
```

Saves `sweep_waypoints.json` (UR joint order: `shoulder_pan`, `shoulder_lift`, `elbow`, `wrist_1`, `wrist_2`, `wrist_3`).

3. With both camera streams up (`/camera_1/color/image_raw`, `/camera_2/color/image_raw`), replay and capture:

```bash
python3 capture_overlay_dataset.py
```

This connects to the robot over **RTDE** at `192.168.77.23`, `moveJ`s each waypoint, then writes:

```
overlay_dataset_2026-07/wp_XX_cam1.png
overlay_dataset_2026-07/wp_XX_cam2.png
overlay_dataset_2026-07/wp_XX_state.json   # actual_q + TCP pose
```

`csamples.yaml` and `js_w.yaml` are extra joint lists (MoveIt-style `joint_names` / `joint_values`), not the overlay sweep.

## Notes

- `ur3e_robotiq.urdf` was generated from `ur_robotiq_gripper.urdf.xacro`. Edit the xacro, not the dump.
- `src/` entries are **nested git repos**, not git submodules. The parent repo records a gitlink (commit SHA) for each. Changes inside `isaac_ros_manipulation` (for example `ur3e_manilab` TFs) live in that nested repo.
- Do not commit `build/`, `install/`, `log/`, or dataset folders.
- `install_deps.sh` must stay in the Isaac ROS container; it uses `${ISAAC_ROS_WS}` and `sudo apt`.
- If Git reports `detected dubious ownership`, the `.git` directory ownership does not match the user running Git. Fix ownership rather than using `sudo git`.
